# C18 - Pull Request (branch → master)

Objectif : travailler via PR comme en entreprise.

## Actions réalisées

1. `git checkout master`
2. `git checkout -b feature/C18`
3. Création du dossier `C18/` avec ce fichier
4. `git add C18/tracabilite.md`
5. `git commit -m "C18: add traceability document"`
6. `git push origin feature/C18`
7. Ouverture d'une Pull Request sur GitHub :
   - Base : `master`
   - Compare : `feature/C18`
   - Titre : "C18: Pull Request feature/C18 → master"
   - Description : "Ajout du dossier C18 dans le cadre du challenge Pull Request."
8. Merge de la PR sur GitHub

## Résultat

- Branche `feature/C18` poussée sur GitHub
- PR créée avec description
- Merge visible dans l'historique GitHub
