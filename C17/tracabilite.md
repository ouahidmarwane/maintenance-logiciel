# C17 - Créer repo GitHub + push

Objectif : publier le projet sur GitHub.

## Actions réalisées

1. Création d'un repo sur GitHub (https://github.com/ouahidmarwane/maintenance-logiciel)
2. Ajout du remote origin :
   `git remote add origin https://github.com/ouahidmarwane/maintenance-logiciel.git`
3. Push de la branche principale :
   `git push -u origin master`

## Résultat

- Repo GitHub contient l'historique complet et tous les fichiers
- Remote `origin` pointe vers : https://github.com/ouahidmarwane/maintenance-logiciel
