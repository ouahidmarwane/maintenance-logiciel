# C16 - Tags (v1.0.0) + push tag

Objectif : versionner une release avec un tag annoté.

## Actions réalisées

1. `git checkout master`
2. Création du dossier `C16/` avec ce fichier
3. `git add C16/tracabilite.md`
4. `git commit -m "C16: add traceability document"`
5. `git tag -a v1.0.0 -m "Release v1.0.0"`
6. `git push origin v1.0.0`

## Résultat

- Tag annoté `v1.0.0` créé sur le commit courant
- Tag visible sur GitHub sous l'onglet "Tags" / "Releases"
